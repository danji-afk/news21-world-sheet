Saturday 21 November 2026: the day's world news on one illustrated page. 36 fact-checked stories — three illustrated lead panels, ten feature cards each with its own vector scene, a vector world map with numbered pins, a stat band, and a date check that names what was left out as earlier-day news. Every story carries a provenance chip (CONFIRMED = 2+ outlets, OFFICIAL = on record, CLAIM = one side, unconfirmed). Claims are attributed; drawings are original vector art (no randomness, no network).

## Run it

```sh
python3 render.py
```

Writes a 1024×1024 PNG to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `.`). Needs
only Python 3, Pillow and cairosvg — no network, no randomness: two runs
produce byte-identical files.
